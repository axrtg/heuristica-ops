PASO 1 — CREAR EL BACKEND EN GOOGLE SHEETS

1. Abre Google Sheets y crea una hoja en blanco → llámala HEURISTICA OPS
2. Menú Extensions → Apps Script
3. Borra todo el contenido y pega el código del archivo apps_script.gs
4. Guarda (Ctrl+S) → ponle nombre: HeuristicaOps

PASO 2 — PUBLICAR EL SCRIPT

1. Menú Deploy → New deployment
2. Tipo: Web app
3. Execute as: Me
4. Who has access: Anyone ← importante
5. Clic en Deploy → autoriza los permisos
6. Copia la URL que aparece (empieza con https://script.google.com/...)

PASO 3 — PEGA LA URL AQUÍ
